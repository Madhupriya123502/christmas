# Christmas Tree Background Video

## Overview
This project is a simple HTML-based webpage that features a full-screen background video with a festive "Merry Christmas!" greeting. The video loops continuously and is muted by default for a smooth user experience.

## Features
- Fullscreen background video 🎥  
- Customizable text overlay 🎄  
- Responsive design for different screen sizes 📱  

## Files Included
- `christmas tree.html` - The main HTML file containing the video and text.  
- `style.css` (Not included but referenced) - For additional styling.  

## How to Use
1. Download or clone this project.  
2. Ensure that the video file (`vecteezy_background-video-merry-christmas-hd-loop_4984757.mov`) is available in the project directory.  
3. Open `christmas tree.html` in any modern web browser.  

## Customization
- To change the text, edit the `<h1>` element inside `christmas tree.html`.  
- To use a different video, update the `<source>` tags inside the `<video>` element with your preferred file.  
- Modify `style.css` to adjust colors, font sizes, or positioning.  

## Browser Compatibility
This project supports modern browsers like Chrome, Firefox, Edge, and Safari.
